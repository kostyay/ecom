# Domain Documents

This repository uses one domain context.

## Read Before Work

- Read `CONTEXT.md` for the approved domain terms and system boundaries.
- Read `docs/architecture.md` for the system plan.
- Read the relevant records in `docs/adr/` before you change an architectural boundary.

If one of these files does not exist, continue without an error.

## Use Approved Terms

Use the terms from `CONTEXT.md` in ticket titles, code, tests, and documents. Do not use a different term for the same domain concept.

## Conflicts

If planned work conflicts with an architecture decision record, identify the conflict. Do not silently replace the decision.
