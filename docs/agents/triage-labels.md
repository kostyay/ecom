# Triage Labels

The engineering skills use five standard triage roles. Record the applicable value in ticket metadata or notes when a workflow requires a triage state.

| Role | Value | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer must evaluate the ticket. |
| `needs-info` | `needs-info` | Work waits for information from the reporter. |
| `ready-for-agent` | `ready-for-agent` | The ticket is fully specified and an agent can do the work. |
| `ready-for-human` | `ready-for-human` | The ticket requires work by a person. |
| `wontfix` | `wontfix` | The project will not do the work. |
