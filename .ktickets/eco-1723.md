Correct the Wallapop partial_parsing warning when a page also contains reserved listings or listings removed by local filters.

## Design

Use the existing failed counter. Set the parsed count from found minus failed instead of from the returned item count.

## Acceptance Criteria

FoundCount is the number of source listings. ParsedCount excludes only listings that failed to parse. Reserved and locally filtered listings do not count as parse failures.

Add one focused Wallapop test with a parsed listing, a filtered or reserved listing, and a malformed listing. Run go test ./providers/wallapop.
