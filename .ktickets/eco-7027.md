# Parse BuscoCotxe car summaries and page metadata

Parse public listing HTML into Product summaries and PageInfo.

## Design

Use golang.org/x/net/html. Scope parsing to car listing cards and validate numeric IDs and website URLs. Read prices from the card overlay; preserve decimal strings. Keep missing prices absent. Use visible summary fields for attributes. Exclude banners and deduplicate IDs. Follow docs/providers/buscocotxe-plan.md.

## Acceptance Criteria

Normal, empty, second, and last pages parse correctly. Numeric EUR prices do not come from finance payments, descriptions, or adjacent cards. Sold and price-on-request states remain accurate. Totals use displayed metadata. Partial failures return partial_parsing counts; unexpected empty HTML returns an error.

## Tests

Add focused offline tests for fixture pages, grouped and decimal money, missing optional fields, finance text, banners, duplicates, invalid URLs, malformed HTML, and partial results. Run go test ./providers/buscocotxe.
